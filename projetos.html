AFFLIST

Este projeto foi feito utilizando ReactJS durante o curso de React da Udemy. O site é uma lista de tarefas onde se pode criar uma nova conta que é salva no banco de dados do Firebase. Apenas com a conta autenticada é possível criar, editar e excluir tarefas.
